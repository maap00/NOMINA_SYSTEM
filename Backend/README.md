# Backend (fase futura)

Esta carpeta reserva el límite para dominio, casos de uso y adaptadores del servidor en una fase posterior. Esta tarea no añade un servidor, una API, una base de datos ni dependencias de backend.

Las reglas de nómina futuras deberán escribirse en TypeScript puro dentro de `Backend/src/`, sin importar React, código de navegador ni SDK de persistencia. El detalle de los límites propuestos está en [`src/ARCHITECTURE.md`](src/ARCHITECTURE.md).
